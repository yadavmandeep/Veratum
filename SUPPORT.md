# Getting Support for Veratum

Thank you for using Veratum! Here are the best ways to get help, ask questions, or report issues.

---

## 📖 Documentation & Guides

Before opening an issue or discussion, check the official documentation:
- **[Quickstart](docs/quickstart.md)**: First task in 3 minutes.
- **[Installation Guide](docs/install.md)**: Setup, enforce, and verify across all 7 IDEs.
- **[Using Veratum](docs/usage.md)**: Prompts, commands, and understanding evidence blocks.
- **[Core Concepts](docs/concepts.md)**: Brain persistence, contracts, ledgers, tree hashes, and blast radius.
- **[IDE Hosts Matrix](docs/hosts.md)**: Detailed breakdown of what each IDE enforces natively.
- **[Troubleshooting](docs/troubleshooting.md)**: Common failure modes, circuit breakers, and fixes.

---

## 💬 Community & Questions

- **GitHub Discussions**: Have a question about how to use Veratum, prompt recommendations, or IDE configuration? Open a discussion in our [GitHub Discussions forum](https://github.com/yadavmandeep/Veratum/discussions).
- **Agent Skill Help**: If you installed Veratum via `skills.sh`, check the skill directory instructions in `.agents/skills/veratum/SKILL.md` or `.claude/skills/veratum/SKILL.md`.

---

## 🐛 Bug Reports & Feature Requests

If you found a bug or want to request a feature:
1. Search [existing GitHub issues](https://github.com/yadavmandeep/Veratum/issues) to see if it has already been reported.
2. If not, open a [new issue](https://github.com/yadavmandeep/Veratum/issues/new) with full reproduction details, IDE, model, and OS.

---

## 🔒 Security Inquiries

For vulnerability disclosures and security concerns, please see our [Security Policy](SECURITY.md) to open a confidential report via GitHub Security Advisories.
